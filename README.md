# Personal Bank Tracker (Java)

A console-based Java application to track money added and removed, view balance, and persist data using file storage.

## Features
- Add money
- Remove money
- View total balance
- View transaction history
- Data persistence using text files

## Concepts Used
- Java basics
- ArrayList
- Loops & conditionals
- Methods
- File I/O (BufferedReader / BufferedWriter)
- Exception handling

## How to Run
1. Clone the repository
2. Open the project in Eclipse / IntelliJ
3. Run `ExpenseTracker.java`
4. Follow the menu instructions

## Files
- `added.txt` – stores added transactions
- `removed.txt` – stores removed transactions
